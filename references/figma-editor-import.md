# 向 Figma 追加粘贴 SVG

1. 打开获授权的 Figma Design 链接。通过链接和当前页面标签确认文件及页面，确认处于编辑状态。只观察用于定向的界面，可用局部视图或目标控件，避免获取原有画布和图层树。
2. 退出文字编辑或属性输入，使画布获得焦点并取消现有选中。将已在本地验证的 SVG 放入剪贴板，通过编辑器的正常粘贴动作追加。按默认落点放置，无需根据原有设计寻找位置或对齐。粘贴方式不可用时，可用编辑器正常导入同一 SVG，继续按追加处理。
3. 仅使用粘贴返回状态、粘贴后的新选区或本次新增对象来确认成功。保留本地 SVG，结果不明确时先核对本次操作结果，避免直接重贴。无法确认时如实报告。

[Figma 官方 SVG 粘贴说明](https://help.figma.com/hc/en-us/articles/360040030374-Copy-assets-between-design-tools)
